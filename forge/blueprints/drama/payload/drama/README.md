# drama/ —— 创作产物

这里是这部短剧的创作区，按六个阶段产出：

| 阶段 | 产物 | 谁产出 |
| --- | --- | --- |
| 立项 | 题材 · 受众 · 集数时长 · 一句话故事 | agent |
| 剧本 | 人物设定 · 故事大纲 · 分场与台词 | agent |
| 分镜 | 镜头表：景别 · 画面 · 时长 | agent |
| 提示词 | 每镜的出图 prompt | `img-prompt` skill |
| 画面 | 每镜的图 | `comfy` skill |
| 成片 | 关键镜头的视频（带原生音频） | `comfy` skill |

## 建议的目录（可调）

```
drama/
├── script/     文本：立项 · 人设 · 大纲 · 分场剧本
├── shots/      分镜表 · 每镜的出图 prompt
└── media/      画面与成片（大文件，默认不进版本库）
```

**目录名与文件划分没有强制规定** —— 按这部短剧的实际需要组织，只要做到
「同一份内容只在一个地方是权威」。

## 两条要紧的

- **别把它当草稿堆** —— 每个文件都是流程产出的正式产物，下游会引用它。
  剧本一改（人设 / 分场动了），受影响的镜头要回头对齐。
- **媒资与文本分开** —— 图与视频体量大、变化快，别和文本混在一处；
  分开后 `.gitignore` 才能只挡媒资、不动文本。
