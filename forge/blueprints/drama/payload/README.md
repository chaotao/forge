# AI 短剧项目

由 `forge new --blueprint drama` 初始化 —— 请把它改成这部短剧真正的一句话。

## 装了什么

三个能力 skill 已装进本项目的各 agent 目录（`.trae` / `.workbuddy` / `.doubao` / `.qoder`
各自的 `skills/`）：

| skill | 干什么 |
| --- | --- |
| `img-prompt` | 把画面文案转成专业出图 prompt；把「现有图 + 改动」转成编辑 prompt |
| `comfy` | 本地 ComfyUI：文生图 / 改图 / 图生 3D / 图生视频（带原生音频） |
| `aiwf` | 创建 / 运行 / 审计 aiwf 工作流（长流程固化成可断点续跑的 run） |

## 从这里开始

**① 定创作方向** —— 题材、受众、集数与单集时长、一句话故事。

**② 让 agent 起步** —— 直接说「按 `drama/README.md` 的链路，从立项和剧本开始」。

**③ 关键节点由你验收** —— 选题、剧本定稿、每批画面的定稿、成片。

> 需要把长流程固化成可断点续跑的 run，用 `aiwf` skill 建工作流 —— 不用等，随时可以。

## 目录

| 位置 | 说明 |
| --- | --- |
| `drama/` | 创作产物：剧本 / 分镜 / 提示词 / 画面 / 视频 |
| `.aiwf/` | 工作流定义与运行记录（若建了流程；`runs/` 进版本库） |
| `.forge/` | 项目状态目录（由 forge 维护；`lock.json` 不要手改） |
| `AGENTS.md` | 人与 agent 共用的约定入口 |
