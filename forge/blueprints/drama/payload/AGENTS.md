# AGENTS.md

本文件是这个 AI 短剧项目里**人与 agent 共用的约定入口**。要改它就单开一次改动说明理由，
别在别处另立一套并行约定。

## 这是个什么项目

一部 AI 短剧的创作工作区。**AI 主创、人工验收** —— 剧本、分镜、画面与视频由 agent 产出，
关键节点（选题、剧本定稿、画面定稿、成片验收）由人来拍板。

## 三个能力 skill（已装进本项目各 agent 目录）

| skill | 角色 | 负责 |
| --- | --- | --- |
| `img-prompt` | **大脑** —— 出提示词 | 把画面文案转成结构化出图 prompt（虚实相生框架）；把「现有图 + 改动」转成编辑 prompt |
| `comfy` | **手** —— 出媒资 | 按 prompt 跑本地 ComfyUI：文生图 / 改图 / 图生视频（输出带原生音频的 `.mp4`） |
| `aiwf` | **流程** —— 记进度 | 创建与运行 aiwf 工作流；把长流程固化成可断点续跑的 run |

**职责边界要守住**：`img-prompt` 只出**词**，不执行；`comfy` 只**执行**，不出词 ——
「写提示词」不要走 comfy，「出图 / 出视频」不要指望 img-prompt。
三者的用法**以各自 skill 的内容为准**，本文件只讲怎么把它们串起来。

## 创作链路（本项目的建议路径）

短剧不像小说那样有一条现成的工作流，本项目按下面这条链路推进：

| # | 阶段 | 干什么 | 交给谁 |
| --- | --- | --- | --- |
| 1 | **立项** | 题材 · 受众 · 集数与单集时长 · 一句话故事 | agent |
| 2 | **剧本** | 人物设定 · 故事大纲 · 分场与台词 | agent |
| 3 | **分镜** | 逐场拆镜头：景别 · 画面 · 时长 | agent |
| 4 | **提示词** | 逐镜写画面描述 → 出图 prompt | `img-prompt` skill |
| 5 | **画面** | 逐镜出图 | `comfy` skill |
| 6 | **成片** | 关键镜头图生视频 → 拼接 | `comfy` skill |

- **一次一镜，不跳步** —— 画面按分镜逐镜推进，别批量补出。
- **改上游要回头对齐** —— 剧本 / 人设 / 分镜是画面的依据，动了它们就检查受影响的镜头。
- **长流程要固化** —— 需要断点续跑、多人协作或人工 checkpoint 时，用 `aiwf` skill
  建一个工作流，别把流程只留在对话里。

## 文件约定

| 位置 | 谁写 | 说明 |
| --- | --- | --- |
| `drama/` | agent | 创作产物：剧本 / 分镜 / 提示词 / 画面 / 视频（见 `drama/README.md`） |
| `.aiwf/` | aiwf 引擎 | 工作流定义与运行记录（**若建了流程**）；`runs/` 要进版本库 |
| `.forge/` | forge | 项目状态目录（`lock.json` 别手改） |
| `AGENTS.md` · `README.md` | 人 | 约定与说明 |

## 进度怎么看

本项目**以创作链路为主线** —— 进度看 `drama/` 下的**产物本身**（剧本 / 分镜 / 提示词 / 画面）；
若把链路固化成了 aiwf 工作流，再看 `.aiwf/runs/`。**默认不另记一套计划**。
`forge plan` 那套「计划 → 任务」账本留给**计划多、周期长的开发类项目**。

> 确有多条线并行排期（如同时推进多部短剧）时，才可选 `forge plan …` ——
> 命令见本项目各 agent 目录里的 **`forge` skill**。

## 干活时的约定

- **一件事一个位置**：同一份内容只在一个文件里是权威，别处引用它，不复制。
- **写之前先看**：动手前先读现行文件，不靠推断。
- **说结论也说说依据**：报结果时给出实际跑过的命令与看到的东西。
- **别顺手扩大范围**：范围外的优化先问，不自己决定。

## 不要做

- 不要手改 `.aiwf/runs/` 下的记录 —— 那是引擎的审计痕迹。
- 不要删 `.forge/` —— 它是这个项目的状态目录。
- 不要提交密钥、令牌或本机绝对路径。
