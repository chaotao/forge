# forge · 设计文档

> **这里的文档是"活的设计意图"，不是权威规范。**
> 事实源是**代码与 skill** —— 实现怎么写、命令怎么用，以 `forge/` 与 `skills/forge/` 为准。
> 推翻一条旧设计，只需写清理由；**不做版本登记、不留决策档案**（历史交给 git）。

---

## 1. 分层

设计**从上层往下层**推进 —— **上面定了，下面才敢往下写**。

| 层                       | 文件                                                                                    | 装什么                                       |
| ---------------------- | ------------------------------------------------------------------------------------- | ----------------------------------------- |
| **L0** 定位与范围          | `00-positioning.md`                                                                   | 定位 · 服务对象 · 用例范围 · 边界 · 明确不做              |
| **L1** 设计原则           | `01-principles.md`                                                                    | 全项目通用原则（约定 **A–H**）                       |
| **L2** 概要架构与模块划分      | `02-architecture.md`                                                                  | 分层 · 数据访问层 · 模块清单与职责 · 接口方向与边界            |
| **L3** 模块设计           | `03-store` · `04-observer` · `05-scaffold` · `06-plan` · `07-inbox` · `08-workbench`  | 每模块一份：模型 · 字段 · 词表 · 接口 · **agent 使用视角** |

**为什么分层**：按"问题流"混着写时，上层一改口，下层成批作废。分层让**上层不改口，下层才敢往下走**。

> ★ **每份 L3 必须含「agent 使用视角」一节**（L1 约定 **H6**）——
> 写清 agent 在**什么场景、按什么步骤、调用哪些命令**用这个模块（完整流程），而不只有模型与接口定义。

**术语**：L0 说的「**能力域**」= L2 / L3 说的「**用例 / 用例模块**」，同一批东西。

---

## 2. 纪律（三条）

| #   | 纪律           | 说明                                                                                                             |
| --- | ------------ | -------------------------------------------------------------------------------------------------------------- |
| **1** | **正文只留结论**   | 不写版本沿革、决策过程、已否方案、裁定审批痕 —— 历史交给 git。                                                                            |
| **2** | **一个概念一个名字** | 模型 / 字段 / 命令 / 文档用同一个词；**不占用上游工具（`aiwf` / `skill`）已用的名字**，冲突时改自己。                                              |
| **3** | **文档不追平实现**  | 文档写**核心设计与关键问题**，实现细节以代码为准；实现变更**无需回改文档**，改设计也**无需回溯登记**。                                                     |
